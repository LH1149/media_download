MediaDownloader V1.0
====================
备份日期：2026-09-28

功能：
- 基于 yt-dlp 2026.08.19 + ffmpeg 7.1（内置）的网页音视频下载器
- 三种下载模式：音视频合并（MP4）/ 仅音频（MP3、M4A、原始格式）/ 仅视频（无声）
- 画质上限选择：4K / 2K / 1080P / 720P / 480P / 最佳画质
- 播放列表防护（默认只下当前视频）、自选保存目录、实时进度/速度/剩余时间、可取消
- 网络容错：yt-dlp 内部 10 次指数退避重试 + 外层 3 轮重试（每轮间隔 30 秒，每轮从零开始）
- 串行下载避免 B站并发限流（503）

已知问题：
- 断点续传（continuedl）与 B站 CDN 时效 URL 冲突会触发 416，故 V1.0 未启用断点续传，
  外层重试每轮重新下载整个分片。
- 失败后残留的 .part 文件需手动删除。

打包：运行 build.bat 即可重新构建 exe（需 pip install yt-dlp pyinstaller imageio-ffmpeg）。
